# Uniqueness of stable allocations in dimensions one and two

Yitzchak Shmalo

Paper: [paper/main.pdf](paper/main.pdf) (source [paper/main.tex](paper/main.tex)).

Hoffman, Holroyd and Peres (A stable marriage of Poisson and Lebesgue, Ann. Probab. 34 (2006)) proved that
Lebesgue measure on $\mathbb R^d$ has a stable allocation to any locally finite set of centres with any appetite,
and that it is unique when the graphs joining centres at bounded distance are recurrent or when the centres come
from a translation-invariant point process. They asked whether some discrete set of centres admits two stable
allocations that differ on a set of positive measure. The paper shows that in dimensions one and two no such set
exists: the stable allocation is unique up to null sets for every locally finite set of centres and every appetite.
In every dimension it is unique when $\sum_k 4^k/(1+N(2^k))=\infty$, where $N(r)$ is the number of centres within
distance $r$ of the origin. The question remains open in dimensions three and higher.

The proof uses no computation.
